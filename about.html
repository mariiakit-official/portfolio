ABOUT ME

Curious by nature, careful by practice.

I’m building a career where quality, analysis, and development meet: understanding the problem first, then testing and building until the solution really works.

01 / HOW I THINK

Problem first

Before I write code or a test case, I want to know who the user is and what is actually going wrong. That habit comes from business analysis and makes everything I build easier to explain.

02 / HOW I WORK

Test, learn, improve

QA taught me to look for what could break. I write test cases, investigate defects, and treat every bug as information about how a system really behaves.

03 / WHAT I BUILD

Practical software

I work with Java, SQL, HTML, CSS, and Git, with hands-on exposure to Spring Boot through an accounting application built on PostgreSQL.
